## Content Format Specs

### Email (Notion Cards Only)

| Field | Newsletter | Feature Spotlight |
|---|---|---|
| Purpose | Weekly value / industry insight | Highlight one Ijadi feature or capability |
| Action | Create card in Notion Marcus Content Calendar | Create card in Notion Marcus Content Calendar |
| Copywriting | Done manually in Notion | Done manually in Notion |

> No drafts produced in this calendar — cards are created as placeholders for manual entry.

---

### YouTube Short

| Spec | Value |
|---|---|
| Max Length | 2 minutes |
| Orientation | Vertical (9:16) |
| Content Focus | Platform tutorials, feature walkthroughs, how-to demos |
| Thumbnail | Custom branded frame |
| CTA | Subscribe + link in bio/description |

---

### Reels (Cross-Platform)

| Spec | Value |
|---|---|
| Length | 30–90 seconds |
| Orientation | Vertical (9:16) |
| Platforms | Facebook, Instagram, LinkedIn, YouTube Shorts |
| Content Types | Quick tips, before/after, myth-busting, feature demos, day-in-the-life |
| Captions | Burned-in subtitles required |

---

### Carousel (Cross-Platform)

| Spec | Value |
|---|---|
| Slides | 5–10 |
| Dimensions | 1080×1080 or 1080×1350 |
| Platforms | Instagram, LinkedIn |
| Content Types | Step-by-step guides, listicles, stat breakdowns, use-case stories |
| Last Slide | CTA — save, share, visit link, or book a demo |

---

### Static Posts

| Spec | Value |
|---|---|
| Dimensions | 1080×1080 (square) or 1080×1350 (portrait) |
| Content Types | Stat cards, quote cards, tip graphics, feature highlights, brand moments |
| Brand | Use Ijadi brand colors, typography, and visual system |

---

### Text Posts

| Spec | Value |
|---|---|
| Length | 150–300 words (LinkedIn), 80–150 words (Facebook) |
| Structure | Hook → Problem/Insight → Solution/CTA |
| Formatting | Line breaks, white space, no walls of text |
| Tone | Calm authority — per Brand Voice & Tone System |

---

### LinkedIn Article

| Spec | Value |
|---|---|
| Length | 800–1,500 words |
| Structure | Headline → Hook → Problem → Insight → Solution → CTA |
| Content Types | Industry POVs, use-case deep dives, operational playbooks, market commentary |
| Tone | Ruler-Sage — authoritative, insight-led, zero hype |

---

### LinkedIn Poll

| Spec | Value |
|---|---|
| Options | 2–4 choices |
| Duration | 1 week |
| Content Types | Industry pain points, preference questions, myth-busting angles |
| Follow-Up | Comment with Ijadi's take after engagement builds |

## Weekly Production Checklist

- [ ] **3 Reels** filmed / edited (cross-platform)
- [ ] **1 Carousel** designed (IG + LI)
- [ ] **1 YouTube Short** recorded / edited (≤ 2 min)
- [ ] **3 Static graphics** designed (LI, FB, IG)
- [ ] **4 Text posts** written (2 LI, 2 FB)
- [ ] **1 LinkedIn Article** written
- [ ] **1 LinkedIn Poll** drafted
- [ ] **2 Notion cards** created in Marcus Content Calendar (Newsletter + Feature)

---

## Workflow Notes

1. **Batch production** — film all 3 reels + 1 YT Short in one session when possible
2. **Asset reuse** — static graphics can share layouts across platforms with dimension adjustments
3. **Cross-posting** — reels are published natively on each platform (not shared links)
4. **Scheduling** — use platform-native schedulers or a unified tool; Notion cards are manual
5. **Brand compliance** — every piece runs through the Brand Voice & Tone System before publishing
6. **Review cycle** — content drafted → reviewed → scheduled (minimum 1 day lead time)
